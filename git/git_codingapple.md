# 코딩애플 git 인강 내용 정리입니다 

# 1. 깃 설치 
윈도우는 git검색해서 설치, 맥북은 homebrew깔고 `brew install git` 하면 됨 

`git config ~~`로 깃 설정을 바꿀 수 있음. 일단 
`git config --global user.email "email.naver.com"`
`git config --global user.name "kkh0208"`
이렇게 초기 세팅을 해놓자 

이렇게 세팅한 정보는 `git config --list` 로 확인 가능

# 2 
이제 작업할 폴더로 들어가서 
`git init`을 해주자. 이 폴더를 깃 폴더로 선언하는것. 
그 결과로 .git이라는, 깃의 메타데이터가 들어있는 폴더가 만들어짐  

`git add file1 file2...` `git add .`　이런식으로 스테이징 에리어에 추가하고 
`git commit -m 'mesg'` 로 레포지토리(저장소)에 올림 
`git log --all --oneline` 으로 지금까지 무슨 작업 했는지 확인 가능 
`git status` 로 지금 무슨 파일이 무슨 상태인지 확인 가능 
add했고 커밋할 준비가 된 애들 => staged
수정은 됬는데 아직 add안한 애들 => unstaged 
깃이 모르는 새파일 => untracked


# 3 
vscode 오른쪽에 창 보면 비주얼적으로 add, commit 가능한 부분 있으니까 터미널로 작업하기 빡세면 고려해보세요 

`git difftool` 명령어로 이전 커밋과 어떤 차이가 있는지 한눈에 비교해주는 툴이 있음. 커밋 전에 확인하는 습관도 좋음 
뒤에 커밋아이디 치면 그 커밋 아이디와 현재랑 차이 비교 가능 
커밋 아이디를 두개 쓰면 두 커밋간의 차이 비교 가능 
커밋 아이디는 위에 log명령어 쓰세요 

근데 이거도 복잡하다! 그러면 그냥 익스텐션에서 git graph 쓰세요 관리 하기 쉬워짐 

# 4 
새 기능을 개발해야 하는데 원본에 개발하는게 무섭다.
그러면 복사본을 만들어서 개발하고 잘 되면 반영하기 이런것도 좋지만 
깃에는 branch라는 기능이 있음.

`git branch 새브런치이름 `으로 현재 커밋 버전에서 독립적인 새 브런치를 만들 수 있다. 
`git switch 브런치이름`으로 현재 내가 있는 브런치를 바꿀 수 있고, 
`git status` 로 내가 어디 브런치에 있는지 알 수 있다. 

새 브런치 상태에서 코드 고치고 커밋하고 한 다음에 메인 브런치로 돌아와도 새로 만든 파일이나 수정사항 들은 다 사라지고 브런치 만들기 전으로 돌아가기 가능 

이제 새 브런치에서 작업 끝내고 잘 된거 같아서 메인 브런치랑 합칠때를 생각해보자. 
우선 두 브런치에서 add 랑 커밋은 마친상태여야 한다.
그리고 메인으로 돌아와서 `git merge 서브브런치이름` 으로 합병하면 됨. 

여기서 만약 서로 다른 파일을 바꿨다면 해피하게 병합완료 

근데 같은 파일을 바꿨다면? 만약 서로 다른줄을 바꾼거라면 병합완료인데 
같은 줄에 대해 바꿨다면 conflict가 일어남. 따라서 둘 중 하나를 선택해야함. 

바꿀 내용으로 선택하고 add , commit다시 하면 병합완료임 .
